# Data Competition 2026

Workspace for the 2026 data competition.

## Structure

```
data/        # raw and processed datasets (not tracked)
notebooks/   # exploration and analysis
src/         # reusable code
outputs/     # submissions, figures, models (not tracked)
```

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
```
